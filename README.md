# FYN Clean Bot

FYN Clean Bot — Telegram-платформа для автоматизации управления клининговым сервисом. Решение объединяет работу клиентов, исполнителей и администраторов в единой системе, позволяя организовать полный цикл обработки заказов: от создания заявки до контроля выполнения и завершения работы.

## Возможности

• Приём и обработка заявок на клининговые услуги  
• Управление заказами и их текущими статусами  
• Работа с клиентской базой  
• Назначение и контроль исполнителей  
• Добавление и хранение фотографий по заказам  
• Система уведомлений о важных событиях  
• Административное управление сервисом  
• Контроль рабочих процессов через Telegram-интерфейс  

## Технологии

Проект разработан с использованием:

• Python  
• Aiogram  
• Telegram Bot API  
• SQL-базы данных  
• Docker  

## Запуск проекта

Для локального запуска необходимо:

1. Клонировать репозиторий:

git clone https://github.com/egorceredov-crypto/fyn-clean-bot.git

2. Установить зависимости:

pip install -r requirements.txt

3. Создать файл `.env` на основе `.env.example` и заполнить необходимые параметры.

4. Запустить бота:

python main.py

## Тестирование

Для проверки стабильности проекта используются автоматические тесты:

pytest -q

## Назначение проекта

FYN Clean Bot создан для автоматизации операционных процессов клинингового бизнеса, снижения нагрузки на сотрудников и повышения эффективности взаимодействия между клиентами, исполнителями и администраторами.

Проект представляет собой готовое решение для управления заказами и рабочими процессами через Telegram.
